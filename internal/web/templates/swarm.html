Rebalance

Swarm only weighs current node load when placing new tasks - it never moves an already-running task onto a node that joined later. After adding or removing nodes, force-restart every replicated service so the scheduler re-places all their tasks across the {{.NodeCount}} node{{if ne .NodeCount 1}}s{{end}} currently in the cluster. Each service still rolls per its own update policy (parallelism/delay/order), so this doesn't take everything down at once. Global-mode services aren't included - they already run one task per eligible node automatically.

Cluster cleanup

Reduce load left over from normal cluster operation: dead task containers that outlived their usefulness, and images/networks/volumes/containers nothing references anymore.

Remove failed tasks
Deletes the leftover container behind every task in failed or rejected state, across all nodes. Running tasks and their history for successful deploys are untouched.
Clean unused resources
Runs a docker system prune equivalent on every node: stopped containers, unused networks, and dangling images. Nothing that's running or in use is touched.
