General settings

Update check

The dashboard shows a banner when a newer swarmdash release is available. Checking it has your browser ask api.github.com for the latest release directly - the admin server itself never talks to GitHub. Turning this off stops that request entirely, not just the banner.

Automatic image updates

Once an hour, move every service whose image has a version tag (1.27.1, v2.3, 8.0.1-jdk17) to the newest tag of the same form in its registry. Patch stays within the current minor version (1.27.1 → 1.27.4), minor within the current major version (1.27.1 → 1.29.0), major takes any newer version (1.27.1 → 2.0.1). Tags like latest are never touched. A service can override this on its page or with the swarmdash.autoupdate label (off, patch, minor, major) under deploy.labels in compose. Each update is recorded in the audit log and sent to webhooks as service_image_updated.
